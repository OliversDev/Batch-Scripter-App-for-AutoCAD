Batch Scripter for AutoCAD

Batch Scripter runs the same AutoCAD script against an ordered list of drawing files.

Start the app

At the AutoCAD command line, enter OW:BatchScripter.

Run a batch

  1. Select Add Drawings and choose one or more DWG or DWT files.
  2. Enter script content or select Add Script to append an SCR/TXT file.
  3. Choose whether changes should be saved.
  4. Select Run Script and confirm the operation.
Drawing order is preserved. Selected drawings must be closed before the batch begins. Test scripts on copies of drawings before using them on production files.

Blank lines and Enter

A blank line following a command response is preserved as an Enter keypress. Blank visual spacing immediately after an AutoLISP expression is ignored, and trailing blank lines are removed.

(command "TILEMODE" "1")
_.ERASE
_ALL

(command "_.REGEN")

Logs and temporary files

Error logs are written under %LOCALAPPDATA%\Batch Scripter\Logs. Generated scripts are written under %TEMP%\BatchScripter and stale scripts are cleaned automatically.
